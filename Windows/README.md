# YX_KazQwerty для Windows

Казахская клавиатура для Windows: казахские буквы на правом Alt и автозамена, которая превращает
казахский, набранный русскими буквами, в правильный. Автозамена та же, что на Mac: тот же словарь и
те же правила, переписанные на Go. На 8 694 настоящих отзывах результат совпадает с версией для Mac
один в один.

> **Бета.** Каждую сборку проверяют на Windows 11 в GitHub Actions: тесты автозамены, сверка с
> версией для Mac и [самопроверка](#самопроверка) (значок в трее, правый Alt, автозамена).
> В живых программах (Word, браузеры, Telegram, Teams) её ещё мало пробовали. Как проверить
> самому, написано [ниже](#проверка).

## Что умеет

- Казахские буквы на правом Alt в обычной русской раскладке Windows. Своя раскладка не нужна:
  хватает двух языков, ENG и РУС.
- Автозамена: «сиздерди шакырамыз» → «сіздерді шақырамыз», «Салеметсизбе» → «Сәлеметсіз бе».
  Русский текст не трогается. Все правила описаны в [README](../README.md#автозамена).
- В интернет ничего не уходит.

| Клавиша (РУС) | а | и | н | г | к | о | у | ц | х |
|---|---|---|---|---|---|---|---|---|---|
| **с правым Alt** | ә | і | ң | ғ | қ | ө | ү | ұ | һ |

С Shift (до или после Alt) или Caps Lock получаются заглавные.

## Запуск

Нужна Windows 10 или 11, 64-битная, и русская раскладка. Устанавливать ничего не нужно:
`YX_KazQwerty.exe` — один файл, словарь внутри.

Скачайте `YX_KazQwerty.exe` со страницы
[последнего выпуска](https://github.com/Bexull/YX_KazQwerty/releases/latest). Сборка самой свежей
версии из `main` лежит в [проверках на GitHub](https://github.com/Bexull/YX_KazQwerty/actions/workflows/tests.yml)
→ последний зелёный запуск → «Artifacts» → `YX_KazQwerty-windows` (нужен вход в GitHub).
Или соберите сами, см. [Сборка](#сборка).

1. Запустите `YX_KazQwerty.exe`. Файл не подписан, поэтому Windows покажет «Windows защитила ваш
   компьютер»: нажмите «Подробнее» → «Выполнить в любом случае».
2. Значок клавиатуры появится в трее. Если его не видно, он под стрелкой ^ возле часов: перетащите
   его на панель задач.
3. Клик по значку → «Запускать при входе в Windows».

Если антивирус удалил файл: программы, которые перехватывают клавиатуру (так работают правый Alt
и автозамена), иногда кажутся ему подозрительными. Верните файл: «Безопасность Windows» →
«Защита от вирусов и угроз» → «Журнал защиты» → «Восстановить».

## Меню значка

- «Казахские буквы на правом Alt» и «Автозамена казахских слов» включают и выключают их.
- «Мои слова для автозамены…» открывает в Блокноте `%APPDATA%\YX_KazQwerty\kazakh-words.txt`.
  Впишите слово в правильном написании, сохраните, и через пару секунд оно исправляется.
- «Не исправлять в «…»» выключает автозамену в программе, где вы были последней. В терминалах,
  редакторах кода, менеджерах паролей и удалённом рабочем столе она выключена сразу.
- «Забыть выученное»: казахское слово, которого нет в словаре, набранное дважды казахскими
  буквами, запоминается; этот пункт всё выученное стирает.

Отменить исправление: ⌫ два раза сразу после него. Первый ⌫ стирает только пробел, так что можно
дописать «!». В поле пароля обычных окон Windows автозамены нет; поля паролей в браузере она
отличить не может.

## Проверка

### Самопроверка

Выйдите из YX_KazQwerty, если он запущен (значок → «Выйти»), и выполните в PowerShell в папке
с файлом:

```powershell
.\YX_KazQwerty.exe --selftest
```

Секунд через 15 откроется Блокнот с отчётом `selftest.txt`. Во время проверки откроется окно
«YX_KazQwerty: проверка клавиатуры» и в нём само напечатается несколько фраз. Не трогайте в это
время клавиатуру и мышь.

Что проверяется:

- Windows, масштаб, тема, раскладки, автозапуск.
- Словарь внутри файла.
- Значок в трее: Windows его принимает.
- Клавиатура целиком: перехват клавиш, правый Alt с Shift, автозамена, отмена двумя ⌫,
  Caps Lock, русский текст. Сравнивается с тем, что должно получиться.

### Вручную

- [ ] Правый Alt + а и н г к о у ц х → ә і ң ғ қ ө ү ұ һ; заглавные с Shift (нажатым до или
      после Alt) и с Caps Lock.
- [ ] Правый Alt + Tab переключает окна; левый Alt работает как обычно.
- [ ] Фразы из таблицы в [README](../README.md), ⌫ после исправления, ⌫⌫ — отмена.
- [ ] В раскладке ENG ничего не меняется, правый Alt обычный.
- [ ] Блокнот, Word, Chrome/Edge (поиск, Google Docs), Telegram, WhatsApp, Teams, Outlook.
- [ ] Windows Terminal: автозамены нет. «Не исправлять в «…»» выключает её в выбранной программе.
- [ ] «Мои слова для автозамены…»: открывается Блокнот; слово, вписанное и сохранённое, через
      пару секунд исправляется.
- [ ] Автозапуск: включить, перезагрузиться, значок на месте.
- [ ] Перезапуск Проводника (Диспетчер задач → Проводник → Перезапустить): значок возвращается.
- [ ] Смена темы Windows: значок в трее меняет цвет.
- [ ] Второй запуск `YX_KazQwerty.exe` ничего не открывает: он уже работает.

Если что-то не так, пришлите `selftest.txt`, снимок экрана и название программы, где это было, или
[расскажите](https://github.com/Bexull/YX_KazQwerty/issues/new?template=bug.yml).

### С Claude Code на Windows

Claude Code на Windows может сам собрать, запустить самопроверку и чинить найденное:

1. Поставьте Git для Windows (https://git-scm.com), Go 1.25+ (`winget install GoLang.Go`)
   и Claude Code.
2. `git clone https://github.com/Bexull/YX_KazQwerty.git` и откройте папку в Claude Code.
3. Попросите: «Прочитай Windows/README.md, собери Windows-версию, запусти самопроверку и пройди
   со мной чек-лист».

Из Git Bash отчёт самопроверки печатается прямо в терминал: `./dist/YX_KazQwerty.exe --selftest`.

## Сборка

Нужен Go 1.25 или новее; собирается на Windows (в Git Bash), macOS и Linux:

```bash
cd Windows
./build.sh
```

Скрипт кладёт словарь из `../Resources/kazakh` внутрь программы, прогоняет тесты автозамены,
`go vet` и собирает `dist/YX_KazQwerty.exe`. Только стандартная библиотека Go, без cgo.
`go run ./cmd/typetest ../Resources/kazakh фразы.txt` показывает, что автозамена сделает с каждой
строкой файла.

## Как устроено

- `kazakh/`: сама автозамена, перенос `Sources/Keyboard/KazakhTyping.swift` и соседних файлов. Её
  тесты — те же, что у версии для Mac, и те же наборы фраз из `Tools/TypingTests`.
- `keyboard_windows.go`: низкоуровневый перехват клавиатуры: правый Alt и автозамена.
- `main_windows.go`, `settings_windows.go`: значок в трее, меню, настройки, автозапуск.
- `selftest_windows.go`: самопроверка. `layout_windows.go`: компилятор сверяет размеры структур
  Windows с теми, что ждёт система.
